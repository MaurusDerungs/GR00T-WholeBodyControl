How To Use

1. Accept the certificate warning if the browser asks for it. This bridge uses a local self-signed HTTPS certificate so WebXR can run on your LAN.
2. Press Start VR Session and allow immersive VR access.
3. Hold both controllers in a neutral pose, then activate teleop from GR00T with the keyboard l to calibrate the robot to your current pose.
4. Left thumbstick drives translation, right thumbstick drives yaw. Triggers close the fingers in the default Quest mapping used by the GR00T bridge.
